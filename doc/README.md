## 1. 项目基本信息

### 1.1 项目简介

这是一个基于 Ruby on Rails 8.1.1 开发的**课程选课管理系统**，支持学生选课、教师查看授课信息等功能。系统采用角色权限控制，目前支持三种角色：

- **学生（Student）**：可以浏览课程、选课、退课、查看课程表、统计学分
- **教师（Teacher）**：可以查看所授课程、查看课程学生名单
- **管理员（Admin）**：可以编辑教师、学生、课程信息，暂未实现功能

### 1.2 核心功能

**学生功能模块：**
- 课程浏览与筛选（按课程名称、课程类型、上课时间）
- 在线选课（自动检测课程满员、时间冲突、重复选课）
- 已选课程管理（查看、筛选、退课）
- 课程表可视化展示
- 学分统计（按课程类型统计已修学分）

**教师功能模块：**
- 查看所授课程列表
- 查看课程学生名单

**系统特性：**
- 基于 Session 的用户认证
- 课程容量控制（防止超额选课）
- 上课时间冲突检测
- 学年学期管理
- 课程类型分类（公共必修/选修、专业必修/选修）

## 3. 项目部署

### 3.1 环境要求

- Ruby 3.3.10 或更高版本
- Bundler 2.x
- SQLite3
- Git

### 3.2 安装步骤

#### 步骤 1：克隆项目

```bash
git clone <https://github.com/RevoltNihility/UCAS_SE_Course-Selection-Web_2025.git>
cd course-selection
```

#### 步骤 2：安装依赖

```bash
bundle install
```

如果遇到 gem 安装问题，可以尝试：

```bash
bundle config set --local path 'vendor/bundle'
bundle install
```

#### 步骤 3：数据库初始化

```bash
# 创建数据库、加载 schema、运行 seed 数据
bin/rails db:setup
```

或者分步执行：

```bash
bin/rails db:create      # 创建数据库
bin/rails db:migrate     # 运行迁移
bin/rails db:seed        # 加载种子数据
```

**注意：** `db:seed` 会创建：
- 100 个学生账号（包括 1 个主测试账号 + 99 个随机账号）
- 约 40 门课程（涵盖公共必修/选修、专业必修/选修）
- 16 位教师账号（对应课程教师）
- 部分满员课程的选课记录

#### 步骤 4：验证安装

```bash
# 运行测试套件
bundle exec rspec

# 检查代码风格
bin/rubocop

# 安全扫描
bin/brakeman --no-pager
```

## 4. 项目运行

### 4.1 启动开发服务器

```bash
bin/rails server
```

或使用简写：

```bash
bin/rails s
```

服务器默认运行在 `http://localhost:3000`

### 4.2 访问应用

在浏览器中打开：

```
http://localhost:3000
```

你将看到欢迎页面，点击"登录"按钮进入登录页面。

### 4.3 停止服务器

在终端中按 `Ctrl + C` 停止服务器。

### 4.4 其他常用命令

```bash
# 打开 Rails 控制台（用于调试）
bin/rails console

# 查看路由
bin/rails routes

# 重置数据库（清空并重新加载）
bin/rails db:reset

# 回滚最后一次迁移
bin/rails db:rollback
```

### 6.2 浏览和选择课程

#### 功能入口

点击导航栏 **"我的选课" → "选课"**，或直接访问 `/my_courses/select_courses`

#### 功能说明

此页面展示所有可选课程（不包括已选课程），支持多条件筛选。

#### 筛选功能

**1. 按课程名称筛选**

在"课程名称"输入框中输入关键词（如"数据"），点击"筛选"按钮，系统会显示所有包含该关键词的课程（如"数据结构"、"数据库系统"、"数据挖掘"）。

**2. 按课程类型筛选**

在"课程类型"下拉框中选择：
- 不限（默认）
- 公共必修
- 公共选修
- 专业必修
- 专业选修

**3. 按上课时间筛选**

在"上课时间"输入框中输入时间（如"1:1"表示周一第1节），系统会显示该时间段有课的所有课程。

**时间格式说明：**
- `1:1` - 周一第1节
- `1:1-2` - 周一第1-2节
- `3:5-6` - 周三第5-6节

**4. 组合筛选**

可以同时使用多个筛选条件，例如：
- 课程名称："机器"
- 课程类型："专业选修"
- 上课时间："1:9"

点击"筛选"后，系统会显示同时满足所有条件的课程。

#### 课程信息展示

每门课程显示以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 课程名称 | 课程的完整名称 | 数据结构 |
| 课程代码 | 课程的唯一标识 | CS201 |
| 学分 | 该课程的学分数 | 4 |
| 课时 | 总课时数 | 64 |
| 教师 | 授课教师姓名 | 陈教授 |
| 课程类型 | 课程分类 | 专业必修 |
| 上课时间 | 每周上课时间 | 周一 1-2节, 周三 5-6节 |
| 已选/容量 | 当前选课人数/最大容量 | 45/80 |
| 操作 | 选课按钮 | [选课] |

#### 选课操作

**步骤 1：** 找到想要选择的课程

**步骤 2：** 点击该课程右侧的"选课"按钮

**步骤 3：** 系统会进行以下检查：

1. **重复选课检查** - 如果已选过该课程，显示提示："您已经选过这门课程了"
2. **课程容量检查** - 如果课程已满员，显示提示："选课人数已满，无法选课"
3. **时间冲突检查** - 如果与已选课程时间冲突，显示提示："该课程与XXX时间冲突"

**步骤 4：** 如果所有检查通过，系统显示"选课成功"，并自动刷新页面

**步骤 5：** 选课成功后，该课程会从可选列表中消失（因为已选课程不再显示）

#### 选课示例

**示例 1：成功选课**

1. 在选课页面找到"数据结构"课程
2. 确认该课程未满员（如 45/80）
3. 确认时间不冲突
4. 点击"选课"按钮
5. 看到"选课成功"提示
6. 该课程从列表中消失

**示例 2：课程满员**

1. 尝试选择"人工智能导论"（CS411）
2. 该课程显示 30/30（已满）
3. 点击"选课"按钮
4. 看到"选课人数已满，无法选课"提示

**示例 3：时间冲突**

1. 假设已选"高等数学A"（周一 1-2节）
2. 尝试选择"概率论与数理统计"（周一 1-2节）
3. 点击"选课"按钮
4. 看到"该课程与高等数学A时间冲突"提示

- 课程名称

- 上课地点（如果有）

## 附录

### 数据模型关系图

```
User (用户)
├── role: student/teacher/admin
├── has_one :student
└── has_one :teacher

Student (学生)
├── belongs_to :user
├── has_many :enrollments
└── has_many :courses (through: :enrollments)

Teacher (教师)
├── belongs_to :user
├── has_many :teachings
└── has_many :courses (through: :teachings)

Course (课程)
├── has_many :enrollments
├── has_many :students (through: :enrollments)
├── has_many :teachings
└── has_many :teachers (through: :teachings)

Enrollment (选课记录)
├── belongs_to :student
└── belongs_to :course

Teaching (授课关系)
├── belongs_to :teacher
└── belongs_to :course
```
