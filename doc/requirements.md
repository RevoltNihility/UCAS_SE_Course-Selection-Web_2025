# 课程选课管理系统 - 需求设计文档

## 一、登录系统

- 基于 Session 的认证，支持学生/教师/管理员登录
- 角色重定向：登录后根据角色自动跳转
  - 学生 → 已选课程页
  - 教师 → 授课课程页
  - 管理员 → 用户管理页
- 会话管理：登出清除 Session

---

## 二、学生页面

### 2.1 选课功能

- 课程筛选：按名称（模糊搜索）、课程类型、上课时间筛选可选课程
- 选课验证
  - 检查是否已选该课程
  - 检查课程是否满员
  - 检查时间冲突
- 选课记录：创建 Enrollment 记录，包含学年、学期、课程类型

### 2.2 已选课程

- 课程列表：查看已选课程，支持按学期、课程名称筛选
- 退选课程：删除选课记录（需验证归属权）

### 2.3 课程时间表

- 可视化课表：基于表格的周课表（7天×13节课）
  - 支持跨多节课的课程显示（rowspan）
  - 显示课程名称和教师

### 2.4 学分汇总

- 学分计算：计算四类课程学分
  - 公共必修
  - 公共选修
  - 专业必修
  - 专业选修
- 学分对比：对比要求（公共必修20、公共选修15、专业必修15、专业选修12、总计62）

---

## 三、教师页面

### 3.1 授课课程

- 课程列表：查看所授课程列表（仅教师权限）

### 3.2 课程学生

- 学生名单：查看课程的学生名单（按学号排序）（仅教师权限）

---

## 四、课程类型

- 公共必修（public_required）：所有学生必修，要求20学分
- 公共选修（public_elective）：任意选修，要求15学分
- 专业必修（major_required）：专业核心课程，要求15学分
- 专业选修（major_elective）：专业方向选修，要求12学分

---

## 五、选课规则

- 时间冲突检测：检测新选课程与已选课程的节次是否重叠（同一周的相同节次）
- 课程容量限制：选课人数不得超过 max_enrollment
- 禁止重复选课：同一门课程不能重复选择
- 选课记录同步：Enrollment 的 course_type 同步 Course 的 course_type
